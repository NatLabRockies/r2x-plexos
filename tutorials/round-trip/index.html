Read, inspect, and export a PLEXOS model

By the end, you will have parsed a public model, exported a native model, and loaded a portable archive to check its component graph. This is a format round trip; it does not run PLEXOS optimization or establish numerical equivalence.

flowchart LR
  XML["PLEXOS XML<br/>Model: Base"] --> P["PLEXOSParser"]
  P --> S["Typed PLEXOS system<br/>objects and memberships"]
  S --> E["PLEXOSExporter<br/>template: PLEXOS10.0"]
  E --> X["RoundTrip_2024.xml<br/>plus any profile CSVs"]
  S --> Z["system.zip<br/>inspect with r2x read"]

1. Confirm the prerequisites

Section titled “1. Confirm the prerequisites”

Complete Installation, environment setup and verification first. The CLI must discover plexos-parser and plexos-exporter in its managed environment.

This tutorial uses a macOS/Linux shell, curl, network access for the pinned downloads, and a new working directory. A licensed PLEXOS installation is not required for this XML exercise.

Where to go next

Section titled “Where to go next”
  • Inspect fields and time series before changing model data.
  • Use Python contexts when inserting custom analysis between parsing and export.
  • Translate PLEXOS to Sienna uses the separate r2x-plexos-to-sienna package and r2x-sienna exporter.
  • Public API and defaults explain what each configuration field controls.

This walkthrough was executed with CLI 0.1.15 and Python 3.12, using r2x-plexos 0.3.3, r2x-core 0.8.0, and Infrasys 1.2.0.
