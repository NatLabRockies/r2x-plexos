title: "r2x-plexos"
---

`r2x-plexos` reads PLEXOS model data into typed R2X systems and exports systems back to PLEXOS.
Use Python for inspection and custom transformations, or `r2x-cli` for repeatable pipelines.
Model translation between PLEXOS and Sienna belongs to the [R2X translation plugins](https://natlabrockies.github.io/R2X/).
